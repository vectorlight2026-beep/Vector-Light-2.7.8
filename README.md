# 🎛️ Vector Light - Professional DMX Controller

DMX512 protokolü ile çalışan profesyonel aydınlatma kontrol sistemi.

**Version:** 2.7.8  
**Geliştirici:** Erkan Uyar  
**Lisans:** Tüm hakları saklıdır


## ✨ Özellikler

- 🎛️ **512 DMX Kanalı** — Tam kanal kontrolü
- 🎚️ **20 Submaster** — Sahne kayıt ve oynatma
- 🎨 **6 Kategori Efekt** — Intensity, Position, Color, Beam, Focus, Playback
- 💥 **BUMP Özelliği** — Anlık vuruşlar
- 🔐 **Şifreli Bağlantı** — AUTH key doğrulama
- 📡 **OTA Güncelleme** — Kablosuz firmware
- 🎨 **12 Tema** — Kişiselleştirilebilir arayüz
- 🌍 **TR / EN Dil** — Çift dil desteği
- 🔒 **Kontrol Kilidi** — Yanlışlıkla dokunmayı önler
- 🔋 **Pil Göstergesi** — Durum çubuğunda
- 🎨 **Kanal Renklendirme** — İsim ve renk atama
- 🔐 **Kanal Kilitleme** — Hassas kanalları korur
